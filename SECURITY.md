# Security Policy

## Supported Versions

| Version | Supported          |
| :------ | :----------------- |
| 0.1.x   | ✅ Yes             |

## Reporting a Vulnerability

If you discover a security vulnerability in HWCode, **please do NOT open a public GitHub issue.**

Instead, report it privately by emailing:

📧 **shadow1q2w3e4r5@gmail.com**

**Subject line:** `[SECURITY] Brief description of the vulnerability`

### What to Include

- Description of the vulnerability
- Steps to reproduce (if applicable)
- Impact assessment (what an attacker could do)
- Suggested fix (if you have one)

### Response Timeline

- **Acknowledgment:** Within 48 hours
- **Initial Assessment:** Within 7 days
- **Fix & Disclosure:** Coordinated with the reporter

### Safe Harbor

We consider security research conducted in good faith to be authorized. We will not pursue legal action against researchers who:

- Report vulnerabilities privately through the above channel
- Avoid accessing or modifying other users' data
- Give us reasonable time to fix issues before disclosure

Thank you for helping keep HWCode safe! 🛡️
